# Nicholas Gittins portfolio

A responsive, accessible static portfolio for archives, special collections, and digital preservation roles. Content follows `BigCV_nick.docx`.

## Local preview

Use Node 20 or newer.

```sh
npm ci
npm run build
npm run dev
```

Open http://127.0.0.1:4173. Rebuild and refresh after source edits. `npm run check` checks generated links, anchors, assets, and basic document metadata.

## Editing

- `src/site.js`: identity, contact email and phone number, project copy, and experience.
- `scripts/build.mjs`: shared templates and page content.
- `src/styles.css`: Tailwind CSS entrypoint and editorial design system.
- `src/site-client.js`: keyboard animation handling; reading and navigation work without JavaScript.
- `src/assets/nicholas-gittins-original.png`: Nicholas's supplied portrait, preserved unchanged. Its warm, desaturated appearance is a CSS filter, not a generated replacement.
- `src/assets/`: tracked portrait, historic photograph, and exported CV PDF.
- `dist/`: complete deployable static site, regenerated by the build and ignored by Git.
- `BigCV_nick.docx`: supplied source CV; build copies it unchanged for download.

The PDF is an export of the supplied Word document, preserving its wording. If the source CV changes, regenerate `src/assets/nicholas-gittins-cv.pdf` too.

## Hosting

Cloudflare Pages project: `nicholas-gittins`. Production URL: https://nicholas-gittins.pages.dev/.

Source repository: https://github.com/kjbeutler01/nickgittins.

The GitHub Actions workflow in `.github/workflows/cloudflare-pages.yml` builds and checks pull requests. Once the deployment credential is configured, pushes to `main` and manual workflow runs publish to the existing Cloudflare Pages project. Deployment requires the repository Actions secret `CLOUDFLARE_API_TOKEN` (Cloudflare Pages Edit, restricted to the hosting account) and repository variable `CLOUDFLARE_ACCOUNT_ID`. Until configured, builds and checks run normally and the workflow summary explains that publishing was skipped.

Automatic publishing setup is pending at the owner's request. The account variable is already configured. To finish, create a Cloudflare API token with **Account → Cloudflare Pages → Edit**, restricted to the hosting account; save it as `CLOUDFLARE_API_TOKEN` under this repository's **Settings → Secrets and variables → Actions**; then run **Actions → Build and publish portfolio → Run workflow** on `main`. Never paste the token into source files or commit it.

To publish updates directly from this directory:

```sh
npm run deploy
```

The command builds, checks, and publishes `dist` to the production branch (`main`). Wrangler uses your existing Cloudflare login; on a new computer, run `npx --yes wrangler@4.86.0 login` first. No credentials belong in this repository.

Cloudflare reads the security headers from `src/_headers`, copied into `dist/_headers` during the build. No environment variables, backend, database, or paid integration is required by this code. Links expect deployment at the domain root. Publish only `dist`, not the repository root.

To attach a domain, use Cloudflare Dashboard → Workers & Pages → nicholas-gittins → Custom domains. Automatic publishing uses GitHub Actions and Wrangler because this Pages project was created with Direct Upload. Cloudflare's native Git integration would require a new Pages project. The existing `vercel.json` is retained as an optional configuration for that alternate host.

## Design and motion

Inspo references: Wellcome Collection, Works Studio, and Emil Kowalski. Warm paper, charcoal, burgundy, Newsreader headings, and DM Sans body text form the shared design system.

The requested UI Skills MCP is configured globally as `ui-skills` at https://www.ui-skills.com/mcp and was checked with `tools/list` and `get_skill`. Its `baseline-ui` guidance informed this build. Emil Kowalski's `animate` skill is installed globally in Codex and was read with its animation recipes.

Motion uses CSS with IntersectionObserver for scroll entry: an 800ms first-view entrance with an 80ms stagger, a 1000ms portrait entrance, 650ms once-per-visit project and section reveals, 160ms press feedback, and 180ms link feedback. Reduced-motion users get a brief opacity change without positional motion or delayed scroll content. Keyboard navigation immediately reveals all content. No autoplay or continuously moving content.

Headings use direct professional labels, without slogan/sub-slogan pairs or decorative italic lines. The portrait, burgundy practice section, and bordered project entries provide restrained visual variety.
